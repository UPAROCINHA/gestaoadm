# gestaoadm
Site/APP para gerir serviços, prazos e outros
UPA ROCINHA — GESTÃO DA MANUTENÇÃO | LAYOUT INSTITUCIONAL v2

Abra index.html no navegador para experimentar. Não são necessárias dependências.
Arquivos: index.html, style.css, app.js, schema.json, assets/logo-upa.png.

PUBLICAÇÃO NO GITHUB PAGES
1. Faça backup da versão atual do site.
2. Envie os arquivos e a pasta assets para a pasta do site de manutenção no repositório.
3. Se o site é publicado na raiz, coloque os arquivos na raiz; se em subpasta, mantenha os caminhos relativos.
4. Aguarde o GitHub Pages publicar. A atualização do site remoto NÃO foi realizada por este pacote.

ATENÇÃO
- Dados ficam no localStorage deste navegador, não há sincronização, login ou backend.
- Os indicadores refletem somente registros cadastrados; o painel inicia vazio, sem dados fictícios.
- Identificação digitada não é assinatura eletrônica autenticada.
- Faça exportações JSON periódicas; importação de IDs iguais substitui registros locais.
- Não insira dados de pacientes. Os anexos são referências, não arquivos enviados.
- A versão 2 mantém schemaVersion 1.0 e a chave localStorage anterior para preservar compatibilidade com dados existentes no mesmo endereço/origem.
